# 05 环路接入指南（SOP 的固件部分，v3 定版）

> 本文回答：**"我要测某个环，代码该改哪两行？"**
> 这是整个项目最需要"教会别人"的部分，也是 SOP 第 3 章的内容来源。
> v2 变更：GH 定义改为 TI 的 `Y/(Inj−Y)`（用户只传反馈量）、"in 口诀"限定为 Plant 模式、补电流环 PWM 同步采样、5.5/5.6 合并。

---

## 5.1 一句话原理（v2 修正版）

两种扫频，接线完全不同：

> **扫 Loop Gain（闭环）**：把正弦加在**该环的参考值**上，`monitor(0, 该环的反馈)`。**只需要反馈一个量**——环路增益由库内部的注入复振幅算出：$GH = Y/(I_{nj} - Y)$（TI 同款定义，01 文档 1.7.1）。
>
> **扫 Plant（开环）**：把正弦加在**执行量**（占空比/电压指令）上，`monitor(叠加后的执行量, 反馈)`。`in` 口诀：**最终进入执行器的那个量**。
>
> **测内环时，外环必须冻结**（两种扫频都一样）。

## 5.2 万能模板（任何单环，同一份 ISR 支持两种模式）

```c
void CONTROL_ISR(void) {
    /* 1. 读反馈（用户原有代码） */
    float y = ADC_Read();                        // 该环的反馈量（pu）

    /* 2. 注入（★第 1 处改动）—— 必须在 monitor 之前，且不推进 θ */
    sfra_signal_t inj = sfra_inject(&sfra);      // 产正弦 + 计时 + 累加 Inj

    /* 3. 用户原有控制律（不动），注入按模式加到不同位置 */
    float r    = ref_dc  + inj;                  // LOOP 模式：加在参考
    float x    = x_dc    + inj;                  // PLANT 模式：加在执行量（开环）
    float u    = Compensator_Run(&comp, r, y);   // 补偿器输出（PLANT 时被丢弃）
    float exec = (sfra.cfg.mode == SFRA_MODE_PLANT) ? x : u;   // 进执行器的量（限幅前）

    /* 4. 采集（★第 2 处改动） */
    sfra_monitor(&sfra, exec, y);
    /* PLANT: 累加 X(exec)、Y(y) → PC 算 H = Y/X
       LOOP : 忽略 in，只累加 Y(y) → PC 算 GH = Y/(Inj−Y) */

    /* 5. 推进相位（★第 3 处改动，最容易漏） */
    sfra_advance(&sfra);                         // 必须在 monitor 之后

    /* 6. 输出（用户原有代码）—— 限幅在这里做，但它变换后的值不参与测量 */
    PWM_Update(exec);
}
```

`ref_dc` 可以是电流给定、电压给定、速度给定、位置给定、功率给定——**核心库不关心**。

**五条硬规则**（违反任何一条，数据会错但不报错）：

1. `inject → monitor → advance` **每周期各调一次、顺序不能变**，不要放进 `if`；
2. `advance()` 挪到 `monitor()` 之前，整条曲线偏 `360/data_count` 度（高频 −30°），且这个错误看起来像"被控对象相位算错"，极难自查；
3. 叠注入的位置是**限幅/饱和之前**，`monitor` 的 `in` 必须是叠完注入的原始值；
4. `out` 用**本周期刚采到的 AD** ，不要用上一周期的缓存值；
5. `exec` 的限幅**保留**（安全），但要知道：一旦限幅生效，该频点数据即失真 → 置饱和标志（01 文档 1.10）。

## 5.3 按环路类型的具体落点

### 5.3.1 单电流环（平均电流控制 Buck）—— 你最关心的场景

| 项目 | 扫 Loop Gain（闭环） | 扫 Plant（开环） |
|---|---|---|
| 注入点 | `Iref` | 占空比 `d = d_dc + inj` |
| monitor 的 in | 忽略（传 0） | 叠加后的占空比 |
| monitor 的 out | `iL`（ADC） | `iL`（ADC） |
| 测到 | **电流环环路增益 $T_i$** ← 你要的"电流环真实 Bode"，PM/GM 从这读 | 从占空比到电感电流的功率级特性 |
| 注入幅值起点 | 稳态电流的 1%~2% pu（正式值由预扫反推，04 文档 D16） | 同左 |

> ⚠️ **电流采样时刻（SOP 必讲）**：iL 通常用 **PWM 同步采样**（计数器中点或开通时刻触发 ADC）以避开开关尖峰。这个时刻直接决定高频段相位——采样点提前/推迟半个开关周期，高频相位差可达数十度。改采样时刻后必须重新扫频，不能混用新旧曲线对比。
>
> ⚠️ 若有 **峰值限流/过流保护**比较器，注入造成的电流峰值不得触发它；触发一次，该频点数据作废（饱和标志会提示）。

### 5.3.2 单电压环（电压模式 Buck）

| 项目 | 扫 Loop Gain | 扫 Plant |
|---|---|---|
| 注入点 | `Vref` | 占空比 |
| in | 忽略 | 叠加后的占空比 |
| out | `Vo` | `Vo` |
| 测到 | 电压环环路增益（含 LC 双极点、ESR 零点、ZOH+采样延迟） | 占空比→输出电压 |

### 5.3.3 双环串联 —— 测内环（电流环）

**关键：电压外环必须冻结。** 冻结的意义：外环若继续调节，会不断改写 Iref 把注入"顶掉"，测出来的是乱码。

```c
void CONTROL_ISR(void) {
    float iL = ADC_IL();

    /* 外环冻结：iref_hold 固定（推荐方式 A：切手动） */
    float iref = iref_hold + sfra_inject(&sfra);      // 注入加在 Iref
    float u    = PI_Run(&i_loop, iref, iL);

    sfra_monitor(&sfra, u, iL);     // PLANT 模式才用 u；LOOP 模式库自动忽略
    PWM_Update(u);
}
```

**三种"冻结外环"写法**：

| 方式 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| **A. 切手动**（推荐） | 置 `manual_flag=1`，外环不执行，`iref_hold = 常量` | 最干净，零干扰 | 外环积分状态丢失，恢复要防冲击 |
| B. 冻结积分 | 外环继续跑但积分项不更新 | 状态保持 | 比例项仍有微弱干扰 |
| C. 输出直通不变 | 外环照跑、输出丢弃、用常量 | 实现最简 | 积分器漂移（windup），恢复冲击大 |

**恢复护栏**：解除冻结时把外环积分器预置为当前实际所需值，防 PID 输出突跳。

### 5.3.4 双环串联 —— 测外环（电压环）

| 项目 | 扫 Loop Gain | 扫 Plant |
|---|---|---|
| 注入点 | `Vref` | 占空比 |
| in | 忽略 | 最终占空比（内环输出） |
| out | `Vo` | `Vo` |
| 测到 | **电压环环路增益 $T_v$**（内环此时是闭合的，$T_v = G_v\cdot\frac{1}{H_v}\cdot\frac{T_i}{1+T_i}$，即外环"看到"的对象乘上自己的补偿器） | 内环闭合后的等效对象 $\frac{1}{H_v}\cdot\frac{T_i}{1+T_i}$ |

> ⚠️ 常见写错：把外环的被测对象写成 $G_v\cdot H_v$ 或 $G_v\cdot\frac{T_i}{1+T_i}\cdot H_v$——**漏了 $1/T_i$ 的开环抵消**。内环闭合后，从 Iref 到 Vo 的传递函数是 $\frac{1}{H_v}\frac{T_i}{1+T_i}$，不是 $\frac{T_i}{1+T_i}$。低频段 $T_i$ 很大时两者看似只差 $1/H_v$，但那是几十 dB 的直流增益差，拿来做"模型对照"必然对不上。

```c
float iref = PI_Run(&v_loop, vref + sfra_inject(&sfra), vo);   // 注入在外环 ref
float u    = PI_Run(&i_loop, iref, iL);                        // 内环照常闭合
sfra_monitor(&sfra, u, vo);    // LOOP 模式 in 被忽略；PLANT 模式 in=最终占空比
```

### 5.3.5 电机三环（位置 → 速度 → 电流）

规则统一：**测哪环，注入加在哪环 ref，out 取该环反馈；外侧环全部冻结**。

| 测哪环 | 注入 | out | 要冻结 |
|---|---|---|---|
| 电流环 | `Iq_ref` | `Iq` | 速度环、位置环 |
| 速度环 | `ω_ref` | `ω` | 位置环 |
| 位置环 | `θ_ref` | `θ` | 无（最外层） |

扫 Plant 时才需要 `in`（= 该环输出最终送进下一级的那个量）。LOOP 模式一律只传反馈。

### 5.3.6 功率环 / 其他自定义环

同一规则。例：功率环（`P_ref` → 电流环 → PWM），扫 Loop Gain 时注入 `P_ref`、out 取 `P` 计算值。

> `P = V·I` 是乘积量，小信号近似 $P \approx V_0 I_0 + V_0\tilde i + I_0\tilde v$，本身带交叉项。注入幅值要更小，且**必须做双幅值校验**确认线性度。

## 5.4 扫 Plant 的特殊要求（唯一要改运行状态的操作）

| 拓扑 | 开环怎么做 |
|---|---|
| Buck / Boost / Buck-Boost（电压型） | 断开电压环，`duty = D_dc + inject()`，`D_dc` 手动给到目标工作点 |
| 峰值/平均电流型 | 电流环保留（它是"功率级的一部分"），断开电压外环，在电流给定上注 → 得到"电流环闭合后的功率级等效" |
| LLC / 谐振 | ⚠️ 不建议：Vout 随负载漂、轻载易进 Burst（进 Burst 后曲线全废）→ 只扫闭环 GH，见 5.4.2 |
| 无桥 PFC | ❌ 禁止开环（电流失控，无保护）→ **只扫闭环 GH**，见 5.4.2 |

> **安全提示（SOP 加框）**：开环时输出不受控。确认 OVP/OCP 有效、电子负载/限流电阻能吸收输出、`D_dc` 从小到大缓调到目标工作点。

> **`D_dc + inject()` 必须留在限幅之前**，并且注意：开环时 Vout 会随注入摆动，
> 若注入幅值取到"输出电压变化 ±5%"以上，负载和电感可能进入饱和/DCM，
> 曲线就不再是小信号结果。**开环扫 Plant 的幅值上限比闭环更严**，建议先跑预扫。

### 5.4.1 扫不到的频率：f_s/5 是硬上限（不看拓扑）

固件在 `sfra_start()` 里把扫频终点钉在 **`f_act ≤ f_s/5`**（`SFRA_NYQ_DIV = 5.0f`），
`vec_length` 会被裁到有效点数。理由不是奈奎斯特（那是 f_s/2），而是**每周期采样点**：

| 每周期点数 | 相位精度（±1 样本抖动） | 可用性 |
|---|---|---|
| ≥ 20 | < 1° | 好 |
| 8 ~ 20 | 1° ~ 5° | 可用，注意噪声 |
| 4 ~ 8 | 5° ~ 10° | 勉强，`< 4` 时上位机标黄 |
| < 4 | > 10°，且谐波混叠 | **没有意义**，标灰剔除 |

`f_s/5` 恰好对应"每周期 5 点"，是这条曲线的实用下限。
**所以**：100 kHz 开关频率的 Buck，最多扫到 20 kHz；想测到 40 kHz 就得把 ISR 做到 200 kHz。

> 上位机 `SweepConfig` 里 `f_nyq = isr_freq / NYQ_DIV`、`f_nyq_requested`
> 会检测"你填的终点超出了上限"，并在点数标签上标琥珀色 + tooltip 提示。
> **固件与上位机用的是同一个 5**（`SFRA_NYQ_DIV` ↔ `sweep_config.NYQ_DIV`），
> 改一边必须改另一边，否则界面承诺 68 点、实际扫出 47 点（S4 踩过）。

### 5.4.2 哪些拓扑只能扫 Loop Gain，不能扫 Plant

| 拓扑 | 扫 Plant | 说明 |
|---|---|---|
| Buck / Boost / Buck-Boost | ✅ 可以 | 断开外环，占空比手动给 |
| 电流型（峰值/平均） | ✅ 可以 | 保留电流环，断开电压环，注在电流给定 |
| **LLC / 串联谐振** | ⚠️ 技术上可以，**但不建议** | 开环时增益由 `f_sw` 决定，Vout 随负载剧烈漂，很容易过压；**且轻载可能进 Burst 模式，一进 Burst 曲线就是废的**。只扫 Loop Gain 就够（PM/GM 本来就只看闭环） |
| **无桥 PFC** | ❌ 不要 | 开环 = 电流失控，毫无保护。**只扫 Loop Gain** |
| 逆变器（并网） | ❌ 不要 | 开环输出电压无人约束 |

**原则**：扫 Plant 的目的是"给补偿器设计提供被控对象模型"。
如果你的补偿器已经凑好、只想知道"现在稳不稳"，**只需扫 Loop Gain**，不必冒开环的风险。

## 5.5 检查清单 + 典型坑（合并版，测前逐条打勾）

**接线正确性**：
- [ ] 注入只加在一处（LOOP：参考值；PLANT：执行量），没有叠加到别处？
- [ ] PLANT 模式的 `in` 是"叠加后的执行量"，不是 `x_dc`，也不是扰动本身？
- [ ] `monitor()` 在 PWM 更新之前、`inject()` 之后调用（in 与 out 同拍）？
- [ ] 测内环前外环已冻结？`ref_dc` 稳定（没有别的环在改它）？
- [ ] 注入叠加点在线幅/饱和**之前**？
- [ ] 注入导致 duty 越界时做了饱和钳位，且饱和标志会置位？

**pu 一致性（00 文档 D15）**：
- [ ] `amplitude`、`in`、`out`、ADC 归一化全部 pu，标定系数写进 meta.json？
- [ ] 换分流器/传感器后重新标定了？

**系统状态**：
- [ ] 扫频期间补偿器限幅已放宽、anti-windup 复位已禁用？
- [ ] 电流环的 PWM 同步采样时刻与上次扫频一致？

**安全与运行**：
- [ ] 串口掉线 MCU 500ms 自动停注入？
- [ ] `sfra_background_task()` 与 `sfra_proto_poll()` 都在主循环被调用？
- [ ] 开环扫 Plant 前 OVP/OCP/电子负载已确认？

**典型坑速查**：

| 症状 | 真实原因 |
|---|---|
| Plant 谐振处没有峰 | 工作点进了 DCM；或注入太大推出 CCM |
| GH 高频相位比预期"超前" | PLANT 的 in 取在 PWM 之后（ZOH 被排除）→ 相位假好 |
| 低频增益随频率漂 | 整周期取整有误 / 没等 settle 就积分 |
| 相位全程 ±180° 反 | 复数约定实现错（查 `bode_data.py` 的 `Z = S_c − jS_s`）；或 in/out 传反 |
| 相位在 ±180° 锯齿跳变 | PC 端没 unwrap；或注入频率接近 f_s/2 混叠 |
| 每次扫结果都不一样 | 外环没冻结 / 负载扰动 / 幅值低于噪声 |
| 改了采样时刻曲线变了 | 正常——同步采样时刻就是被测对象的一部分，重新扫 |
| **LOOP 扫出的 GH 曲线低频增益 ≈ Plant 的 DC 增益** | Inj 累加器没采到（`inject()` 里那段 `acc_mac` 被误删，或 `collected < data_count` 判反），导致 `Inj−Y ≈ −Y`，分母退化成测 Plant |
| **GH 幅值整体小了约 6 dB 或有常数偏移** | `amplitude` 中途被改过（违 D8），`Inj` 与实际注入不是同一个幅值 |
| **进度条到 50% 就停住** | 上位机还在用"LOOP 耗时 ×2"的旧公式。D19 改为单 pass 后，PLANT 与 LOOP 耗时相同（02 文档 2.2.1） |
