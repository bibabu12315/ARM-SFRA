## 三、最容易混淆的三组（看这里，别重复读）

### 04 与 10：都是"验证"，但一个是**体系设计**，一个是**验收方法论**

| | 04 验证路线 | 10 验收路线 |
|---|---|---|
| 回答 | L0/L1/L2/L3 **分别证明什么**，L 层与 S 阶段怎么对应 | **验收时拿什么当基准**，三条曲线怎么互证 |
| 独有内容 | L 层 ↔ S 阶段映射表；**三个护栏**（预扫反推幅值、ABORT 三来源、扫频中冻结系数） | **三层对照法**（连续域 / Tustin / ZOH+延迟）；第 0 关 4 条自洽判据；每关失败定位表 |
| 什么时候读 | 要判断"这个测试属于哪一层、够不够格进下一层" | 要做验收、要出报告、要解释"为什么这个偏差算合格" |

> 一句话：**04 管"测几层"，10 管"拿什么比"。**
> 10 的开头已写"前置阅读：04"，但很多人只读了 10 就以为 04 是旧版 —— 不是。

### 07 与 10：一个是**清单**，一个是**原理**

07 是"照着打勾"，10 是"为什么这么判"。10 的 §10 已经写明分工，这里重申：
- **日常回归** → 跑 `tools/accept.py`（它串起 07 的清单）
- **有争议 / 出问题** → 回 10，按"三条曲线"重新定位

### 08 与 07：一个是**结果**，一个是**方法**

08 是 `accept.py` 跑出来的报告（含原始输出），不要手改、不要当文档读。
要看"怎么验的"去 07，要看"上次验的结果"才去 08。
